# 0009 — Local Maps grid rank

## Grid math

- `gridSize` must be odd (5, 7, 9). Pin count = `gridSize²`.
- Pins are generated by `buildGridPins()` centered on `(centerLatitude, centerLongitude)` with corner pins ~`radiusKm` from center.
- DataForSEO `location_coordinate` format: `lat,lng,radiusMeters` (default 500m).

## Matching

- Target business matched by `place_id` or `cid` in Maps SERP items (`matchMapsResultRank`).
- Stored rank is `rank_absolute` when present.

## Cost

- `pins × keywords × $/Maps task` using `estimateLocalMapScanCost()` and `dataforseo-pricing.ts`.
- Manual scans use live pricing; scheduled scans use queued task_post (~30% of live).

## Orchestration

- Workflow id === run id. Partial unique index prevents concurrent runs per campaign.
- Scheduled cron advances `nextCheckAt` before starting workflow.
